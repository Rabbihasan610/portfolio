# Rabbi Hasan Portfolio

A responsive, data-driven portfolio built with HTML, CSS, and vanilla JavaScript.

## Edit content

Update `assets/data/content.json` to change services, case studies, email, GitHub, or LinkedIn links.

## Run locally

```powershell
python -m http.server 8080
```

Open `http://localhost:8080`.

## Free hosting

- Netlify: drag this entire folder into Netlify Drop.
- GitHub Pages: push the folder to a repository and enable Pages from the main branch.
- Cloudflare Pages: connect the GitHub repository; no build command is required and the output directory is `/`.

The contact form uses FormSubmit. The first submission sends an activation email to the portfolio email address. Confirm it once to enable delivery.
